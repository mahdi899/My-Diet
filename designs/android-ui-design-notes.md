## پنل کاربر

Use case: ui-mockup. Create a polished high-fidelity Android MOBILE APP UI design presentation for a Persian nutrition app called «سبزینه». This is an actual native mobile application visual concept, not a website or desktop dashboard. Output ONE landscape design board containing FOUR distinct portrait Android screen designs side by side, each with a slender dark phone frame and full screen content visible. All four phones equally sized and generously spaced on a warm pale sage studio background. No browser bars, no web navigation, no sidebars, no desktop widgets, no role switching UI. Native Android status bars, comfortable 48dp touch targets, Persian RTL typography that looks like Vazirmatn, large readable titles, rounded 20dp surfaces, restrained elegant emerald green / cream / pale pistachio palette, charcoal text with strong contrast. Beautiful contemporary professional consumer app, spacious minimal styling, thoughtfully drawn thin line icons, tasteful photoreal food photography on a meal card, Android bottom navigation with 4 items home, plan, followup, profile. Design for 390x844 dp each phone. Every Persian word must be correctly joined and RTL. No English inside the phone UIs. Board heading above the screens, exact Persian: «سبزینه | اپلیکیشن برنامه غذایی»; smaller subtitle «پنل کاربر». Put short Persian screen labels below each phone.
Screen order from RIGHT TO LEFT: 1) Home dashboard titled «سلام سارا» with secondary «برنامه‌ات در حال بررسی است», avatar and notification icon. The main feature is a large VERTICAL native stepper timeline card titled «وضعیت برنامه» with 5 steps: «ثبت درخواست» checked, «بررسی اطلاعات» checked, «تهیه پیش‌نویس» checked, «بررسی متخصص» current amber pill, «برنامه آماده» grey. Below a compact doctor card «دکتر نازنین رضایی» and a clear outlined button «پیام به متخصص». Bottom navigation active «خانه». 2) Multi-step questionnaire screen top native back arrow, title «کمی از خودت بگو», small «مرحله ۲ از ۶», thin progress bar, main question «هدفت از دریافت برنامه چیه؟», four stacked large selectable cards with tasteful icons and radio controls: «تغذیه متعادل» selected light pistachio with green border, «مدیریت وزن», «بهبود عادت غذایی», «با راهنمایی متخصص». Large bottom anchored primary button «ادامه». No bottom tab bar during this focused flow. 3) Approved daily plan screen titled «برنامه غذایی من», green check badge «تأیید متخصص», horizontal seven-day selector with «یکشنبه» active, primary meal card with attractive real salad food photo and text «ناهار» and «بشقاب سبزیجات», two smaller meal rows «صبحانه» and «شام» with recognizable icons, portion and time microcopy kept concise, clear button «درخواست تغییر برنامه», bottom navigation active «برنامه». 4) Profile screen titled «پروفایل من», avatar and «سارا احمدی», small pill «اطلاعات تکمیل شده», clean native list groups with chevrons: «اطلاعات فردی», «ویرایش پرسش‌نامه», «برنامه‌های قبلی», «سفارش‌ها و پرداخت‌ها», «یادآوری‌ها», «پشتیبانی», «حریم خصوصی». Bottom navigation active «پروفایل».
No medical claims, no calorie prescriptions. Make the visual read instantly as native Android app screen designs, not a responsive website. Avoid excessive decorative elements and illegibly tiny text. Show all phone screens fully, never crop.
