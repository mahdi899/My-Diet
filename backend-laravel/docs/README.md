## ❓ سؤالات متداول

### چرا PHP 8.4 لازمه؟
پروژه Laravel روی PHP 8.4 configure شده. برای تست می‌تونی:
- PHP upgrade کنی
- یا Composer dependencies رو adjust کنی

### آیا تغییرات breaking هستن؟
خیر. تغییرات backward compatible هستن. فقط بهینه‌سازی و بهبود.

### چطور هزینه رو کنترل کنم؟
در جدول `ai_controls`:
- `per_request_cap_micros`: مثلاً ۵۰۰٬۰۰۰ = $0.50 per plan
- `daily_cost_cap_micros`: سقف روزانه
- `kill_switch`: خاموش کردن کامل

### اگه تست شکست خورد چی؟
۱. بررسی لاگ‌ها: `storage/logs/draft-*.txt`
۲. مطالعه بخش "در صورت مشکل" در `TESTING_GUIDE.md`
۳. بررسی error code در جدول `ai_generations`

### کجا می‌تونم نتایج رو ببینم؟
```bash
# نمایش demo
php scripts/demo_optimization.php

# بررسی metrics واقعی (بعد از تست)
php artisan tinker --execute="
\$metrics = app(\App\Modules\Plans\Application\PlanGenerationMetrics::class);
print_r(\$metrics->requestMetrics('YOUR_REQUEST_ID'));
"
```
