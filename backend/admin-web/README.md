# پنل وب مدیریت سبزینه

## اجرای آماده روی این سیستم

در PowerShell از پوشه `backend`، دستور `powershell -ExecutionPolicy Bypass -File .\start-admin.ps1` را اجرا کنید و `http://localhost:3000/admin/` را باز کنید. این اسکریپت PostgreSQL محلی پایدار روی پورت 54329 و API روی پورت 3000 را اجرا می‌کند و به MySQL یا Apache در XAMPP وابسته نیست. اطلاعات دیتابیس در `backend/.pgdata` و اطلاعات حساب محلی در فایل نادیده‌گرفته‌شدهٔ `backend/.env.local-admin.json` ذخیره می‌شوند. این فایل را منتشر نکنید. سرور فقط روی دستگاه محلی گوش می‌دهد. بستن پردازش Node، API را متوقف می‌کند؛ اجرای مجدد همین دستور اطلاعات را نگه می‌دارد.

پنل با همان سرور API در `http://localhost:3000/admin/` ارائه می‌شود؛ نیازی به سرور فرانت‌اند یا CORS جدا نیست. این آدرس لوکال است و هنوز روی اینترنت منتشر نشده است.

## راه‌اندازی

در پوشه `backend`، وابستگی‌ها و دیتابیس را طبق README اصلی آماده کنید و `npm run migrate` را اجرا کنید. سپس با متغیرهای محیطی `DATABASE_URL` و `PHONE`، دستور `npm run admin:create` را اجرا کنید. برای حساب ایجادشده، `ADMIN_USERNAME` و `ADMIN_PASSWORD` را نیز تنظیم کنید و `npm run admin:password` را اجرا کنید. رمز باید ۱۲ تا ۲۵۶ کاراکتر باشد؛ هیچ رمز پیش‌فرضی وجود ندارد. پس از تنظیم رمز، متغیر رمز را از محیط حذف کنید.

با `npm run start:dev` سرور را اجرا و `/admin/` را باز کنید. نشست از کوکی HttpOnly برای تمدید استفاده می‌کند؛ توکن دسترسی فقط در حافظه مرورگر است. پس از پنج تلاش ناموفق حساب برای ۱۵ دقیقه قفل می‌شود. ورود دومرحله‌ای فعال‌شده برای حساب رعایت می‌شود.

فهرست‌ها از API واقعی خوانده می‌شوند؛ در صورت نبود دیتابیس یا نشست معتبر، اطلاعات نمایشی جایگزین نمی‌شود. داشبورد تعداد ردیف‌های اخیر API را نشان می‌دهد، نه شمارش کل دیتابیس. امکان بررسی نظرات معلق و ویرایش تعرفه و پاداش فراهم است؛ امکانات دیگر API مانند ویرایش پرسش‌نامه و انتساب درخواست هنوز در این رابط اضافه نشده‌اند.

برای استقرار، سرور و Postgres و HTTPS لازم است؛ فایل‌های پنل در Docker image هم قرار دارند. اپ موبایل همچنان داده‌های نمایشی خود را دارد؛ اتصال کامل صفحه‌های کاربر و پزشک به API، بخشی جدا از انتقال پنل ادمین است.
