# سبزینه

نقشهٔ پوشه‌ها در [STRUCTURE.md](STRUCTURE.md) است.

| پوشه | محتوا |
|---|---|
| `app/` | اپ Flutter |
| `site/` | سایت |
| `demo/` | فرم ثبت‌نام وب |
| `admin/` | پنل ادمین |
